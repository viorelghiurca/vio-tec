# Vio-Tec Logo

Alle Dateien haben einen **transparenten Hintergrund**. Text ist in Vektorpfade
umgewandelt – die Inter-Schrift muss also nirgends installiert sein.

## Welche Datei wofür?

| Datei | Einsatz |
|---|---|
| `vio-tec-logo.svg` | **Standard für ERP, Rechnungen, Briefpapier** (heller Hintergrund) |
| `vio-tec-logo-1024.png` | Wenn das ERP kein SVG akzeptiert (Fallback: `-2048` für Druck, `-512` für Web) |
| `vio-tec-logo-white.svg/.png` | Auf dunklem Hintergrund (Website-Header, Präsentationen) |
| `vio-tec-logo-mono-black.svg/.png` | Einfarbig – Fax, Stempel, S/W-Druck, Gravur |
| `vio-tec-icon.svg/.png` | Nur die Kachel – Avatar, App-Icon, Social Media, Favicon |
| `vio-tec-icon-mono-black.*` | Einfarbige Kachel |

PNG-Größen: Zahl im Dateinamen = Breite in Pixel.

## Farben

- Primär-Gradient: `#4f46e5` → `#818cf8`
- Wortmarke „Vio": `#111827`
- Wortmarke „-Tec": `#4f46e5` (auf dunkel: `#a5b4fc`)

## Schutzraum

Rundum mindestens die halbe Höhe der Kachel freihalten. Logo nie verzerren –
immer proportional skalieren.
